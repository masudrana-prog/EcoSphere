EcoSphere: Smart Tree Plantation, Monitoring & Sustainability PlatformEcoSphere is a centralized web platform designed to streamline personal carbon footprint tracking, facilitate tree plantation, and verify environmental contributions through direct integration with nurseries and NGOs. Features & Core ModulesUser Web PortalCarbon Footprint Calculation: Estimate monthly carbon emissions based on electricity, water usage, household waste, and transportation data.  Consumption Tracking: Log resource usage over time and visualize environmental impact trends.  Plantation Submissions: Locate approved planting zones, view available tree species, and submit plantation evidence including photos and location data.  Gamified Sustainability: Earn EcoPoints, unlock achievement badges, improve Green Scores, and rank on community leaderboards upon verification.  Nursery & NGO PortalInventory & Stock Management: Nurseries manage tree and sapling listings, update stock availability, set pricing, and process sapling requests.  Plantation Verification: Authorized NGOs inspect user-submitted photos and evidence to approve or reject plantation claims with detailed feedback.  Automated Point Allocation: Verifications automatically trigger point distribution to user profiles.  Admin DashboardStakeholder Moderation: Review, approve, or suspend accounts for users, nurseries, and NGOs.  System Analytics: Track overall plantation statistics, EcoPoint distributions, active challenges, and system logs.  Rules & Content Control: Configure reward policies, set badge requirements, and handle reported disputes.  🛠️ Technology StackLayerTechnologyFrontendHTML5, CSS3, JavaScript, Bootstrap  BackendJava, Spring Boot  Persistence & DatabaseSpring Data JPA, MySQL  ArchitectureModel-View-Controller (MVC), REST APIs  🏗️ System ArchitectureThe platform utilizes an MVC (Model-View-Controller) architectural pattern supported by a centralized relational database:  View Layer: Responsive HTML/Bootstrap interface accessible across desktop, tablet, and mobile browsers.  Controller Layer: Spring Boot REST controllers managing authentication, data transfer, and request routing.
